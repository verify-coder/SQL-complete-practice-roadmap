# 🚀 SQL Roadmap | Beginner to Advanced

A structured **SQL practice journey** designed to build strong database and data analysis skills through **327+ hands-on questions** using MySQL.

📌 **Topics Covered:**
SELECT • Filtering • Sorting • Aggregations • GROUP BY & HAVING • JOINs • Subqueries • CASE WHEN • CTEs • Window Functions • RANK • LAG/LEAD • SQL Interview Preparation

📊 **Capstone Project:** Supermarket Sales Analysis using real-world business queries and data.

🎯 **Goal:** Strengthen SQL problem-solving skills, prepare for **Data Analyst interviews**, and gain practical experience with real-world data analysis.
